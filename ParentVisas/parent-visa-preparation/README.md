**Version 0.1.1.** A portable preparation skill for Australian Parent 103, Aged Parent 804, Contributory Parent 143/173, Contributory Aged Parent 864/884 and Sponsored Parent (Temporary) 870. Subclass 870 covers both obtaining sponsorship approval and preparing the visa application. The skill can organise a checklist, check document consistency, help read a Department request or create a next-step plan. It does not determine legal eligibility, lodging validity, visa status or document acceptance.
