## Quick start: Download → Drag → Ask

1. **Download the Immigent® skill ZIP.** Open the [release page](https://github.com/ScriptSavvy/AustraliaVisaSkills/releases/tag/Parent_visas) and choose the skill ZIP under **Assets**, not **Source code**.
2. **Drag the ZIP into your AI chat.**
3. **Send this message:**

   > Please install this skill. Ask before replacing an existing copy. If you can’t install it, tell me whether you can use it in this chat.

If your app can’t open the ZIP, see [Other ways to install (including terminal commands)](INSTALL.md#other-ways-to-install). You don’t need to share any visa documents to get started.

**Version 0.1.1.** A portable preparation skill for Australian Parent 103, Aged Parent 804, Contributory Parent 143/173, Contributory Aged Parent 864/884 and Sponsored Parent (Temporary) 870. Subclass 870 covers both obtaining sponsorship approval and preparing the visa application. The skill can organise a checklist, check document consistency, help read a Department request or create a next-step plan. It does not determine legal eligibility, lodging validity, visa status or document acceptance.
