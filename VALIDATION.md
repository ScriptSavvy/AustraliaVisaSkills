# Validation scope — public edition 0.2.0

## Checks performed for this release
- Public entry point, references, report template and installation/usage guides authored as standalone Markdown.
- Installation paths compared with saved official product documentation retrieved on 2026-10-07. This is a documentation check, not native installation testing on each platform.
- Release packaging checks parse YAML, resolve local Markdown links and required supporting files, scan for machine-local paths and forbidden private source files, verify the official licence text, and test archive integrity/content equality.

The packaging command output is the authority for whether those structural/archive checks passed. No script executes visa policy decisions or authenticates documents.

## Behavioural evidence and limits
The source-backed predecessor underwent an independent seven-scenario synthetic walkthrough: normal preparation, missing information, conditional minor/dependant checks, inconsistent dates, uncertain extraction, conflicting/unavailable sources and negative exemption controls. The minor timeline was clarified afterwards. This was a model walkthrough, not an automated test suite or real applicant/platform integration.

The new public edition is a simplified derivative. The predecessor walkthrough does **not** prove that this edition was independently behaviour-tested. Its workflow retains the uncertainty gates; fresh public-edition behavioural and cross-platform integration review remains recommended before broad deployment.

## Policy limits
Targeted English/financial sources were checked; comprehensive current-law verification, all subsidiary instructions, account features and professional/legal review have not been completed. The executing agent must verify applicable requirements for each task. Unknown or blocked checks remain Needs verification.

## Publication limits
No GitHub repository has been published by this packaging work. Owner/rights-holder details and commercial contact require confirmation before publication. Public archives omit internal research, raw source snapshots and applicant data. The internal edition is separately packaged and must not be publicly uploaded.
