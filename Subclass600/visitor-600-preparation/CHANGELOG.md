# Changelog

## Visitor 600 — 0.3.3
- Answers focused questions directly, with the supported finding and concrete next action instead of unnecessary full intake.
- Puts main findings and priority actions before detailed broad-review tables.
- Clarifies first-use notices, required source checks and continued question numbering.

## Visitor 600 — 0.3.2
- Added question numbering and exact or estimated totals, with explanations when the total changes.
- Added a brief first-use CC BY-NC 4.0 non-commercial licence notice before applicant intake.

## Visitor 600 — 0.3.1
- Applicant intake now asks one question at a time, adapting to answers and avoiding repeated questions.
- Supports unsure/skipped answers, urgent-request priority and a grouped questionnaire only when the applicant explicitly prefers it.

## Visitor 600 — 0.3.0
- Added form/submission, unavailable-document, correspondence/request and terminology guidance.
- Distinguished ordinary separate applications from the potential newborn mechanism; current applicability remains a verification check.

## Visitor 600 — 0.2.0
- Expanded detailed guidance for funding, sponsorship, minors and unusual visit activities.
- Updated official-source checks while retaining relevant uncertainty and stream limits.

## Visitor 600 — 0.1.0
- Added document-preparation support for the Visitor visa, with installation and usage guides.
