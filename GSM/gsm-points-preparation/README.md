## Quick start: Download → Drag → Ask

1. **Download the Immigent® skill ZIP.** Open the [release page](https://github.com/ScriptSavvy/AustraliaVisaSkills/releases/tag/gsm-points) and choose the skill ZIP under **Assets**, not **Source code**.
2. **Drag the ZIP into your AI chat.**
3. **Send this message:**

   > Please install this skill. Ask before replacing an existing copy. If you can’t install it, tell me whether you can use it in this chat.

If your app can’t open the ZIP, see [Other ways to install (including terminal commands)](INSTALL.md#other-ways-to-install). You don’t need to share any visa documents to get started.

A standalone Australian General Skilled Migration points-claim and evidence preparation skill. Covers 189 Points-tested, 190 and 491, with a dated historical 489 branch. Produces a provisional points breakdown, claim-specific evidence checklist and next actions, not a full visa assessment.

Install the entire `gsm-points-preparation` folder. Read [INSTALL.md](INSTALL.md) and [USAGE.md](USAGE.md). The `GSM` repository wrapper is intentional: this module serves multiple subclasses. It is not a new visa subclass and has no runtime dependency on another skill.
