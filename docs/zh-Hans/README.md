## 安装：下载 → 拖入 → 发送指令

1. **下载 ZIP。** 打开[技能列表](../../README.md#choose-your-skill)，选择所需的签证技能，再打开该行的 **Release page**。在 **Assets** 下下载技能 ZIP，不要下载 **Source code**。所有语言使用同一个技能 ZIP，不需要另找中文版。
2. **把 ZIP 拖入 AI 聊天窗口。** 安装时不需要提供护照、签证申请材料或其他个人文件。
3. **复制并发送这段话：**

   > 请安装这个技能。如果已经有同名技能，请先征得我的同意再替换。如果无法安装，请告诉我能否只在当前聊天中使用它。

如果应用无法打开或安装 ZIP，请在选定技能的同一行打开 **Install**，查看该技能的英文安装指南和其他安装方法。仅上传、读取 ZIP 或在本次聊天中使用它，都不等于已经安装好、能在新聊天中使用。

## 使用：用中文告诉 AI 你需要什么

从[技能列表](../../README.md#choose-your-skill)选一个技能，并保留它的英文名称，不要翻译。打开该行的 **Use**，查看该技能的英文示例和适用范围。把下面示例中的 `student-500-preparation` 换成你所选技能的准确名称，再复制发送：

> 请使用 `student-500-preparation` 技能，用简体中文回答。请帮我列一份初步的签证材料清单，区分必须提供、符合特定条件才需要提供，以及有助于补充说明的材料。如果需要了解我的情况，请一次只问一个问题。还不能确认的事项请标明，不要猜测。

如果只想问一个问题，可以把清单请求换成“请只回答这个材料准备问题：［填写问题］”。如果想核对文件，先提供简要说明或材料清单；需要查看原件内容时，再提供必要的已遮盖敏感信息的页面。上传前请查看 AI 服务商如何处理及保留文件。不要在公开的 GitHub Issues 中提交申请记录。

请把结果当作材料准备建议。**待核实**表示还缺少事实、清晰可读的文件内容或适用的官方来源，不表示不符合要求。AI 用中文解释材料，不代表该译文可作为正式译文提交。有关工作流程、结果状态和限制，请参阅[英文通用使用指南](../../USAGE.md)。

本页是独立的中文入门指南，不包含在技能 ZIP 内。安装方式和实际回答语言取决于你使用的 AI 应用及其支持的功能。
