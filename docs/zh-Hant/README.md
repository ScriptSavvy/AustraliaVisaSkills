## 安裝：下載 → 拖入對話 → 傳送指令

1. **下載 ZIP 檔。** 開啟[技能清單](../../README.md#choose-your-skill)，選擇所需的簽證技能，再開啟同一列的 **Release page**。請在 **Assets** 中下載技能的 ZIP 檔，不要下載 **Source code**。所有語言使用同一個 ZIP 檔，不需要另外下載繁體中文版。
2. **把 ZIP 檔拖入 AI 應用程式的對話視窗。** 安裝時不需要提供護照、簽證申請文件或其他個人資料。
3. **複製並傳送這段話：**

   > 請安裝這個技能。如果已有同名的技能，請先徵得我的同意再取代。如果無法安裝，請告訴我是否可以只在目前的對話中使用它。

如果你的應用程式無法開啟 ZIP 檔或安裝技能，請在所選技能的同一列開啟 **Install**，查看英文指南中的其他安裝方法。能上傳或讀取 ZIP 檔，或能在這次對話中使用技能，不代表已安裝好，也不代表能在新對話中使用。

## 使用：請 AI 用繁體中文回覆

從[技能清單](../../README.md#choose-your-skill)選擇一項技能，並保留它原本的英文名稱。開啟同一列的 **Use**，查看該技能的英文範例及適用範圍。將下方的 `student-500-preparation` 換成你所選技能的確切名稱，再複製並傳送這段話：

> 請使用 `student-500-preparation` 技能，並以繁體中文回覆。請幫我列一份初步的簽證文件清單，區分必須提供的文件、符合特定條件才需要的文件，以及有助於補充說明的佐證資料。如果還需要了解我的情況，請一次只問一個問題。請標明尚未確認的事項，不要猜測。

如果只想問一個問題，可以把列清單的要求換成「請只回答這個文件準備問題：［填寫問題］」。如果想請 AI 檢查文件，請先提供摘要或文件清單。只有在需要查看實際內容時，才分享必要的頁面，並遮蔽不需要的敏感資訊。上傳前請先確認 AI 服務提供者如何處理及保留檔案。不要在公開的 GitHub Issues 貼出申請資料。

請將結果用於文件準備。**待查證**表示仍需查明事實、確認文件內容，或查看適用的官方來源，不代表你不符合要求。AI 提供的中文解說或翻譯有助於理解文件，但不一定可作為正式譯本提交。關於使用流程、結果狀態及限制，請參閱[英文通用使用指南](../../USAGE.md)。

這份繁體中文入門指南不包含在技能 ZIP 檔內。可用的安裝方式及回覆語言取決於你的 AI 應用程式及其支援的功能。
