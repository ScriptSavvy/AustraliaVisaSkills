## インストール：ダウンロード → ドラッグ → メッセージを送信

1. **ZIP をダウンロードします。** [スキル一覧](../../README.md#choose-your-skill)から使うスキルを選び、同じ行の **Release page** を開きます。**Assets** にあるスキルの ZIP を選んでください。**Source code** ではありません。どの言語を使う場合も ZIP は同じです。
2. **ZIP を AI アプリのチャット画面にドラッグします。** インストールにパスポートやビザ申請書類は不要です。
3. **次のメッセージをコピーして送信します。**

   > このスキルをインストールしてください。すでに同じスキルがある場合は、置き換える前に私に確認してください。インストールできない場合は、このチャット内だけで使えるか教えてください。

アプリで ZIP を開けない、またはインストールできない場合は、一覧で選んだスキルの **Install** を開いてください。英語のガイドに別の方法が記載されています。ZIP を添付したり読み取ったり、現在のチャットで使えたりしても、新しいチャットで使えるようにインストールされたとは限りません。

## 使い方：日本語で必要な作業を依頼する

[スキル一覧](../../README.md#choose-your-skill)でスキルを選びます。スキル名は翻訳せずそのまま使ってください。同じ行の **Use** を開くと、そのスキルの例や利用範囲を英語で確認できます。次の `student-500-preparation` を選んだスキルの正確な名前に置き換え、コピーして送信してください。

> `student-500-preparation` スキルを使い、日本語で回答してください。ビザの書類チェックリストのたたき台を作ってください。必須の書類、特定の条件に該当する場合のみ必要な書類、補足として役立つ資料を分けてください。情報が必要な場合は、一度に一つずつ質問してください。確認できていないことは明示し、推測で補わないでください。

質問が一つだけなら、リストの依頼を「次の書類準備の質問だけに答えてください：［質問］」に変えられます。書類を確認してほしい場合は、まず概要か一覧を共有してください。実物の確認が必要になったときだけ、不要な個人情報を隠した該当ページを共有します。アップロード前に、AI サービスによるファイルの処理と保存の扱いを確認してください。公開の GitHub Issues に申請書類を投稿しないでください。

結果は書類準備の参考として使ってください。**要確認**は、事実、書類の内容、または適用される公式情報源の確認が必要という意味です。要件を満たしていないという意味ではありません。AI による理解のための翻訳が、そのまま提出用の正式な翻訳として認められるわけではありません。[英語の共通利用ガイド](../../USAGE.md)もご覧ください。

この日本語ガイドは ZIP に含まれません。利用できるインストール方法や回答の言語は、お使いの AI アプリによって異なります。
