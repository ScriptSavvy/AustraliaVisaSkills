# Immigent®: วิธีติดตั้งและใช้สกิลเตรียมเอกสารวีซ่าออสเตรเลีย

[English](../../README.md)

> **ข้อควรทราบ:** สกิลเหล่านี้ให้ข้อมูลทั่วไปและช่วยเตรียมเอกสารเท่านั้น ไม่ใช่คำแนะนำทางกฎหมาย และไม่สามารถใช้แทนคำแนะนำจากตัวแทนด้านการย้ายถิ่นฐานที่ขึ้นทะเบียนหรือผู้ประกอบวิชาชีพกฎหมายที่มีคุณสมบัติในออสเตรเลียได้ ไม่มีการรับประกันการอนุมัติวีซ่า ระยะเวลาดำเนินการ หรือผลอื่น ๆ ด้านการย้ายถิ่นฐาน โปรดตรวจสอบข้อกำหนดอย่างเป็นทางการและตัดสินใจเองว่าจะยื่นเอกสารใด สกิลและคู่มือให้ใช้ตามสภาพที่เป็นอยู่ ภายในขอบเขตที่กฎหมายที่ใช้บังคับอนุญาต ผู้สร้าง ผู้ดูแล และผู้เผยแพร่ไม่รับผิดชอบต่อความสูญเสียหรือความเสียหายที่เกิดจากการใช้งานหรือการอาศัยผลลัพธ์ของสกิล ข้อความนี้ไม่ตัดสิทธิหรือความรับผิดที่กฎหมายไม่อนุญาตให้ตัดออก

> **สัญญาอนุญาต: ใช้เพื่อวัตถุประสงค์ที่ไม่ใช่เชิงพาณิชย์** คำแนะนำและคู่มือต้นฉบับของ Immigent® ใช้สัญญาอนุญาต **CC BY-NC 4.0** คุณสามารถใช้ แชร์ และดัดแปลงเพื่อวัตถุประสงค์ที่ไม่ใช่เชิงพาณิชย์ตามเงื่อนไขของสัญญา เมื่อแชร์ให้ระบุที่มาและแจ้งสิ่งที่แก้ไข การใช้เชิงพาณิชย์ต้องได้รับอนุญาตแยกต่างหากจากผู้ทรงสิทธิ์ เอกสารของรัฐบาลและบุคคลภายนอก ข้อมูลของผู้ยื่นคำขอ และซอฟต์แวร์ที่มีสัญญาอนุญาตแยกต่างหาก ยังคงอยู่ภายใต้สิทธิและเงื่อนไขของแต่ละรายการ ดู[สัญญาอนุญาตฉบับเต็ม](../../LICENSE.txt)และ[ขอบเขตกับวิธีระบุที่มา](../../LICENSING.md)

## ติดตั้ง: ดาวน์โหลด → ลากเข้าแชต → ส่งข้อความ

1. **ดาวน์โหลด ZIP** เปิด[รายการสกิล](../../README.md#choose-your-skill) เลือกสกิลที่ต้องการ แล้วเปิด **Release page** ในแถวเดียวกัน ในส่วน **Assets** ให้ดาวน์โหลด ZIP ของสกิล ไม่ใช่ **Source code** ทุกภาษาใช้ ZIP เดียวกัน
2. **ลาก ZIP ไปวางในหน้าต่างแชตของแอป AI** ไม่ต้องส่งหนังสือเดินทางหรือเอกสารคำขอวีซ่าเพื่อติดตั้ง
3. **คัดลอกและส่งข้อความนี้:**

   > โปรดติดตั้งสกิลนี้ หากมีสกิลนี้อยู่แล้ว ให้ขออนุญาตก่อนติดตั้งทับ หากติดตั้งไม่ได้ ให้บอกว่าสามารถใช้สกิลนี้เฉพาะในแชตปัจจุบันได้หรือไม่

หากแอปเปิดหรือติดตั้ง ZIP ไม่ได้ ให้เปิด **Install** ในแถวของสกิลที่เลือก คู่มือภาษาอังกฤษจะแสดงวิธีอื่น การแนบ อ่าน หรือใช้ ZIP ในแชตปัจจุบันไม่ได้หมายความว่าสกิลติดตั้งพร้อมใช้ในแชตใหม่แล้ว

## ใช้งาน: ขอให้ AI ตอบเป็นภาษาไทย

เลือกสกิลจาก[รายการสกิล](../../README.md#choose-your-skill) โดยไม่ต้องแปลชื่อสกิล เปิด **Use** ในแถวเดียวกันเพื่อดูตัวอย่างและขอบเขตการใช้งานเป็นภาษาอังกฤษ เปลี่ยน `student-500-preparation` ในข้อความด้านล่างเป็นชื่อสกิลที่เลือกให้ตรงทุกตัว แล้วคัดลอกไปส่ง:

> โปรดใช้สกิล `student-500-preparation` และตอบเป็นภาษาไทย ช่วยทำรายการเอกสารเบื้องต้นสำหรับเตรียมยื่นวีซ่า แยกเอกสารที่ต้องมี เอกสารที่ต้องใช้เฉพาะเมื่อเข้าเงื่อนไข และหลักฐานเพิ่มเติมที่อาจช่วยได้ หากต้องการข้อมูลเพิ่ม ให้ถามทีละคำถาม ระบุสิ่งที่ยังตรวจสอบไม่ได้และอย่าเดา

หากต้องการถามเรื่องเดียว ให้เปลี่ยนคำขอทำรายการเป็น “ตอบเฉพาะคำถามเกี่ยวกับการเตรียมเอกสารข้อนี้: [ใส่คำถาม]” หากต้องการให้ตรวจเอกสาร ให้เริ่มจากสรุปหรือรายการเอกสารก่อน ถ้าจำเป็นต้องดูเอกสารจริง ให้ส่งเฉพาะหน้าที่จำเป็นและปิดบังข้อมูลละเอียดอ่อนที่ไม่เกี่ยวข้อง ก่อนอัปโหลดให้ตรวจสอบว่าผู้ให้บริการ AI จัดการและเก็บไฟล์อย่างไร อย่าโพสต์เอกสารคำขอใน GitHub Issues ที่เปิดให้บุคคลทั่วไปเห็น

ใช้ผลลัพธ์เพื่อช่วยเตรียมเอกสาร **ต้องตรวจสอบเพิ่มเติม** หมายถึงยังต้องตรวจสอบข้อเท็จจริง เนื้อหาเอกสาร หรือข้อมูลจากแหล่งทางการที่ใช้กับกรณีของคุณ ไม่ได้หมายความว่าคุณไม่ผ่านข้อกำหนด คำแปลที่ AI ทำขึ้นเพื่อช่วยให้เข้าใจเอกสารอาจไม่ใช่คำแปลที่ยอมรับให้ยื่นอย่างเป็นทางการ ดู[คู่มือการใช้งานทั่วไปภาษาอังกฤษ](../../USAGE.md)

คู่มือภาษาไทยนี้ไม่ได้รวมอยู่ใน ZIP วิธีติดตั้งและภาษาที่ใช้ตอบขึ้นอยู่กับแอป AI ที่คุณใช้
