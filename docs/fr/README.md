## Installer : téléchargez, glissez le fichier, envoyez un message

1. **Téléchargez le ZIP.** Ouvrez la [liste des compétences](../../README.md#choose-your-skill), choisissez celle dont vous avez besoin, puis ouvrez **Release page** sur la même ligne. Sous **Assets**, téléchargez le ZIP de la compétence, et non **Source code**. Le même ZIP sert pour toutes les langues.
2. **Glissez le ZIP dans la fenêtre de discussion de votre application d’IA.** Vous n’avez pas besoin de fournir de passeport ni de documents de visa pour l’installation.
3. **Copiez et envoyez ce message :**

   > Installe cette compétence. Si une copie existe déjà, demande-moi mon accord avant de la remplacer. Si tu ne peux pas l’installer, dis-moi si tu peux l’utiliser uniquement dans cette discussion.

Si votre application ne peut pas ouvrir ou installer le ZIP, sélectionnez **Install** sur la ligne de la compétence choisie. Le guide en anglais présente d’autres méthodes. Joindre ou lire le ZIP, ou s’en servir dans la discussion en cours, ne signifie pas que la compétence sera installée pour les prochaines discussions.

## Utiliser : demandez un résultat en français

Choisissez une compétence dans la [liste](../../README.md#choose-your-skill). Ne traduisez pas son nom. Ouvrez **Use** sur la même ligne pour voir ses exemples et ses limites en anglais. Remplacez `student-500-preparation` par le nom exact de la compétence choisie, puis copiez ce message :

> Utilise `student-500-preparation` et réponds en français. Prépare une liste provisoire des documents pour mon dossier de visa. Distingue les documents obligatoires, ceux requis seulement dans certaines situations et les justificatifs utiles. Si tu as besoin d’informations, pose une question à la fois. Signale ce qui reste à vérifier et ne fais pas de suppositions.

Si vous avez une seule question, remplacez la demande de liste par « Réponds uniquement à cette question sur la préparation des documents : [votre question] ». Pour une vérification de documents, commencez par fournir un résumé ou une liste. Si certaines pages sont nécessaires, ne fournissez que celles-ci et masquez les données sensibles inutiles. Avant de télécharger des fichiers dans l’application, vérifiez comment le fournisseur d’IA les traite et les conserve. Ne publiez pas de dossier de demande dans les espaces publics de GitHub Issues.

Le résultat vous aide à préparer vos documents. **À vérifier** signifie qu’un fait, le contenu d’un document ou une source officielle applicable reste à confirmer. Cela ne signifie pas qu’une condition n’est pas remplie. Une traduction produite par l’IA pour vous aider à comprendre un document n’est pas nécessairement recevable comme traduction officielle. Consultez le [guide général d’utilisation en anglais](../../USAGE.md).

Ce guide en français n’est pas inclus dans le ZIP. Les options d’installation et la langue des réponses dépendent de votre application d’IA.
