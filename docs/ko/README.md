# Immigent® 호주 비자 준비 스킬: 설치 및 사용 안내

[English](../../README.md)

> **중요 안내:** 이 스킬은 일반 정보와 서류 준비 지원만 제공합니다. 법률 자문이 아니며, 등록 이민 대리인이나 호주에서 자격을 갖춘 법률 전문가의 자문을 대신하지 않습니다. 비자 승인, 처리 기간 또는 기타 이민 결과를 보장하지 않습니다. 공식 요건을 직접 확인하고 제출할 서류를 결정하세요. 스킬과 안내서는 있는 그대로 제공됩니다. 적용 법률이 허용하는 범위에서 제작자, 유지관리자 및 배포자는 스킬을 사용하거나 그 결과에 의존하여 발생한 손실이나 손해에 대해 책임을 지지 않습니다. 법률상 배제할 수 없는 권리나 책임은 이 안내로 배제되지 않습니다.

> **라이선스: 비영리 사용.** Immigent®의 자체 작성 지침과 안내서에는 **CC BY-NC 4.0** 라이선스가 적용됩니다. 라이선스 조건에 따라 비영리 목적으로 사용, 공유 또는 수정할 수 있습니다. 공유할 때는 출처를 표시하고 변경 사항을 밝히세요. 영리 목적으로 사용하려면 권리자의 별도 허락이 필요합니다. 정부 및 제3자 자료, 신청인 서류, 별도 라이선스가 적용되는 소프트웨어에는 각각의 권리와 조건이 적용됩니다. [라이선스 전문](../../LICENSE.txt)과 [적용 범위 및 출처 표시 안내](../../LICENSING.md)를 참고하세요.

## 설치: 다운로드 → 채팅창으로 끌어다 놓기 → 메시지 보내기

1. **ZIP을 다운로드하세요.** [스킬 목록](../../README.md#choose-your-skill)에서 필요한 스킬을 골라 같은 줄의 **Release page**를 여세요. **Assets**에서 스킬 ZIP을 다운로드하세요. **Source code**는 받지 마세요. 모든 언어에서 같은 ZIP을 사용합니다.
2. **ZIP을 AI 채팅창으로 끌어다 놓으세요.** 설치할 때 여권이나 비자 신청 서류는 필요하지 않습니다.
3. **아래 문장을 복사해 보내세요.**

   > 이 스킬을 설치해 주세요. 이미 설치된 스킬이 있다면 교체하기 전에 제 허락을 받아 주세요. 설치할 수 없다면 현재 채팅에서만 사용할 수 있는지 알려 주세요.

앱에서 ZIP을 열거나 설치할 수 없다면, 목록에서 선택한 스킬의 **Install**을 눌러 다른 설치 방법을 확인하세요. 해당 안내서는 영어로 제공됩니다. ZIP을 첨부하거나 읽을 수 있거나 현재 채팅에서 사용할 수 있다고 해서 새 채팅에서도 사용하도록 설치된 것은 아닙니다.

## 사용: 원하는 작업을 한국어로 요청하기

[스킬 목록](../../README.md#choose-your-skill)에서 스킬을 고르세요. 스킬 이름은 번역하지 마세요. 같은 줄의 **Use**를 누르면 영어로 된 예시와 지원 범위를 볼 수 있습니다. 아래의 `student-500-preparation`을 선택한 스킬의 정확한 이름으로 바꾼 후 복사해 보내세요.

> `student-500-preparation` 스킬을 사용해 한국어로 답해 주세요. 비자 준비용 서류 목록 초안을 만들어 주세요. 필수 서류, 특정 조건에 해당할 때만 필요한 서류, 그리고 도움이 되는 보조 자료를 구분해 주세요. 추가 정보가 필요하면 한 번에 한 가지씩 질문해 주세요. 확인되지 않은 내용은 표시하고 추측하지 말아 주세요.

한 가지만 궁금하다면 목록 요청 대신 “서류 준비에 관한 이 질문에만 답해 주세요: [질문]”이라고 쓰세요. 서류 검토를 요청할 때는 요약이나 목록부터 보내세요. 실제 페이지가 필요한 경우에만 필요한 부분을 공유하고 불필요한 민감 정보는 가리세요. 업로드 전에 AI 서비스가 파일을 어떻게 처리하고 보관하는지 확인하세요. 공개 GitHub Issues에 신청 서류를 올리지 마세요.

결과는 서류 준비에 참고하세요. **확인 필요**는 사실, 문서 내용 또는 적용되는 공식 출처를 더 확인해야 한다는 뜻이지, 요건을 충족하지 못했다는 뜻이 아닙니다. AI가 이해를 돕기 위해 번역한 문서가 공식 제출용 번역으로 인정되는 것은 아닙니다. [영어 공통 사용 안내](../../USAGE.md)를 참고하세요.

이 한국어 안내서는 ZIP에 포함되어 있지 않습니다. 설치 방법과 답변 언어는 사용 중인 AI 앱에 따라 달라집니다.
